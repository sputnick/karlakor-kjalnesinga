# Hver á sér fegra föðurland

Hver á sér fegra föðurland,  
með fjöll og dal og bláan sand,  
með norðurljósa bjarmaband  
og björk og lind í hlíð?  
Með friðsæl býli, ljós og ljóð,  
svo langt frá heimsins vígaslóð.  
Geym, Drottinn, okkar dýra land  
er duna jarðarstríð.  

Ó, Ísland, fagra ættarbyggð,  
um eilífð sé þín gæfa tryggð,  
öll grimmd frá þinni ströndu styggð  
og stöðugt allt þitt ráð.  
Hver dagur liti dáð á ný,  
hver draumur rætist verkum í  
svo verði Íslands ástkær byggð  
ei öðrum þjóðum háð.  
Svo aldrei framar Íslands byggð  
sé öðrum þjóðum háð.  

## Notes

- **Stanzas:** 2 set in the score, 2 written here.
- **Form:** Verse 1 ("Hver á sér fegra föðurland...") is set under the notes. Verse 3 ("Ó, Ísland, fagra ættarbyggð...") is given as a separate clean typed text block below the music rather than as underlay, sung to the same melody; it ends with the poem's own extra two-line repeat ("Svo aldrei framar Íslands byggð / sé öðrum þjóðum háð"), which is part of the published poem, not a plain musical repeat.
- Verified word-for-word against the full poem as published on a site run by Hulda's descendants/estate (hofundurinnhulda.wordpress.com), which also confirms the poem's history (written for the 1944 lýðveldi poetry competition) and that "norðurljósa" (not the OCR's "horðurljósa") is correct. That source shows the complete poem has THREE stanzas; this choir arrangement only sets stanza 1 and stanza 3, omitting the middle stanza ("Hver á sér meðal þjóða þjóð, er þekkir hvorki sverð né blóð / en lifir sæl við ást og óð og auð, sem friðsæld gaf? / Við heita brunna, hreinan blæ og hátign jökla, bláan sæ, / hún uni grandvör, farsæl, fróð og frjáls - við ysta haf."), matching the rule to leave out unused stanzas and note them here. check_song.py flags 'ljóð' in 'Með friðsæl býli, ljós og ljóð,' as a possible credit marking; it is a genuine lyric word here (ljóð = poems/songs), not a credit line, so it is kept.
- **Proofread:** 'Geym, drottinn,' → 'Geym, Drottinn,' (God; score prints 'Drott-inn').
