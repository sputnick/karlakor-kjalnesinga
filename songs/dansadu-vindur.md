# Dansaðu vindur

Vindur já, dansaðu vindur,  
er vetur og kuldi gefa nýjan þrótt.  
Vindur já, dansaðu vindur,  
vertu á sveimi um kalda jólanótt.  

Vindur já, dansaðu vindur,  
af vetri fá börn að finna húsaskjól.  
Vindur já, dansaðu vindur,  
vetur er, færir börnum heilög jól.  

## Notes

- **Stanzas:** 2 set in the score, 2 written here.
- **Form:** Choir (backing) part from the 2014 'Jólagestir Björgvins' concert charts (© 2014 Tónanaust ehf), Úts. Þórir Baldursson. Each of these two 2-line couplets is repeated several times over the course of the piece (bar ranges marked in the score, e.g. 1-4/5-12/23-30/35 for the first pair); each is written once here rather than duplicated. Confirmed online (Kvennakór Akureyrar's own arrangement of the same song) that these two couplets are the recurring 'Vindur, já dansaðu vindur...' refrain lines of a longer song, whose verses ('Kuldinn, hann kemur um jólin...', 'Núna nístir í snjónum...', 'Úti fær vindur að valda...') are carried by the soloist and are not written into this TTBB choir excerpt (which only has 'ah' there) — matching the score's scope exactly, so only the refrain is given here.
- Full song and composer credit confirmed via kvak.is (Kvennakór Akureyrar): music by the Swedish songwriters Peter and Nanne Grönvall, Icelandic words by Kristján Hreinsson (a translated/adapted foreign tune, but only the Icelandic text is set here, per the batch rule).
