# Dansaðu vindur

Vindur já, dansaðu vindur,  
er vetur og kuldi gefa nýjan þrótt.  
Vindur já, dansaðu vindur,  
vertu á sveimi um kalda jólanótt.  

Vindur já, dansaðu vindur,  
af vetri fá börn að finna húsaskjól.  
Vindur já, dansaðu vindur,  
vetur er, færir börnum heilög jól.
