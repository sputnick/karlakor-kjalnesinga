# Jólin alls staðar

Jólin, jólin alls staðar  
með jólagleði og gjafirnar.  
Börnin stóreyg standa hjá  
og stara jólaljósin á.  
Jólaklukkan boðskap ber  
um bjarta framtíð handa þér.  
Og brátt á himni hækkar sól,  
við höldum heilög jól.  

## Notes

- **Stanzas:** 1 set in the score, 1 written here.
- **Form:** Single one-stanza song; all three score sources (typed two-part arrangement, a handwritten lead sheet, and the litla rauða jólabókin version) set the same single verse with no repeats.
- Text matches the published version at snerpa.is exactly except the typed/handwritten scores both clearly set the definite form 'Jólaklukkan boðskap ber' where the web source has indefinite 'Jólaklukka boðskap ber'; kept the score's 'Jólaklukkan' since it is what is actually notated/sung here and is the more standard construction. Title corrected from 'Jólin allsstaðar' (one word) to the standard two-word spelling 'Jólin alls staðar', matching both the score title and the published text.
