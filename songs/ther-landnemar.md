# Þér landnemar

Þér landnemar, hetjur af konungakyni,  
sem komuð með eldinn um brimhvít höf,  
sem stýrðuð eftir stjarnanna skini,  
og stormana hlutuð í vöggugjöf —  
synir og farmenn hins frjálsborna anda,  
þér leituðuð landa.  
Í særoki klufuð þér kólguna þungu,  
komuð og sáuð til stranda.  
Í fjalldölum fossarnir sungu.  
Að björgunum brimskaflar sprungu.  
Þér blessuðuð Ísland á norræna tungu.  
Fossarnir sungu,  
og fjöllin bergmála enn:  
Heill yður, norrænu hetjur.  
Heill yður, íslensku landnámsmenn!  

## Notes

- **Stanzas:** 1 set in the score, 1 written here.
- **Form:** Single continuous poem (excerpt from Davíð Stefánsson's Alþingishátíðarljóð, 1930), set by Sigurður Þórðarson for TTBB choir; no verse/refrain repeats. 'Con moto'/'un poco animato'/'Maestoso' are tempo markings, omitted.
- Full text confirmed against a 1956 Sjómannadagsblaðið quotation reproduced on timarit.is (Lögberg 31.1.1957 reprint), which matches the score's underlay closely. The score itself (and this correction) uses the modern spelling 'íslensku' where the older newspaper source prints pre-1973 orthography 'íslenzku'.
- **Proofread:** no changes
