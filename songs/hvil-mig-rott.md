# Hvíl mig rótt

Hvíl mig rótt, það hallar degi, hvíl mig ljúfa, þögla nótt.  
Vef mig þínum vinarörmum, vagga mér í draumi rótt.  

Hvíldu mig, er höfði þreyttu hinsta sinn ég drjúpi rótt.  
Ber mig þá til bjartra sala, blíða, kyrra stirnda nótt.  

## Notes

- **Stanzas:** 2 set in the score, 2 written here.
- **Form:** Two short stanzas set to the same melody, engraved as two stacked text rows; the final bar is a 1st/2nd-ending repeat giving each stanza its own closing word ("draumi rótt" / "stirnda nótt").
- Transcribed directly from a very clearly engraved, unambiguous score. A search snippet from mbl.is's Ljóðabanki confirms stanza 1 verbatim ("Hvíl mig rótt, það hallar degi, hvíl mig ljúfa þögla nótt. Vef mig þínum..."). A Morgunblaðið death-notice quotation of stanza 2 (timarit.is, paywalled/CAPTCHA-blocked so not directly readable) showed "höfði þreyttur"/"drúpi" where the score's own clear engraving reads "höfði þreyttu"/"drjúpi" (2-syllable "þreyttu" and "drjúpi" both fit the notated rhythm, and a one-off newspaper quotation is not necessarily authoritative), so the score's own reading was kept.
