Halleluja.  

## Notes

- **Form:** Karlakór arrangement (úts. Þórir Baldursson, from 'Jólagestir Björgvins 2014') built almost entirely from numbered instrumental bars (rehearsal cues '4','8','6','8','6','8','4','2','4' etc.); the only text anywhere in the score is the word 'Halleluja' repeated many times near the end over a 12/8 groove.
- This octavo does not set Leonard Cohen's verse lyrics at all — it is an instrumental medley arrangement with only the interjection 'Halleluja' actually sung, so it is flagged needs-review per the 'no sung text / vocalise only' rule rather than treated as the full song.
