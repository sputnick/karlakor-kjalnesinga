# Das Königslied

Ein König ist der Wein!  
Mit Segen reich beladen,  
ist er von Gottes Gnaden  
und mancher Purpur sein.  
Ein König, ein König,  
ein König ist der Wein!  

Ein König ist der Wein!  
Mit seinem Rebenbande  
umschlingt er alle Lande,  
beherrscht sie groß und klein.  
Ein König, ein König,  
ein König ist der Wein!  

## Notes

- **Stanzas:** 2 set in the score, 2 written here.
- **Form:** The score sets these two stanzas as a two-part canon: one voice sings stanza 1 while the other, entering slightly later, sings stanza 2, both converging on the same 'Ein König ist der Wein!' tag; the two are written out separately here in their normal reading order rather than interleaved as printed. The full Kommersbuch poem has 5 stanzas; only the first two are set in this score/arrangement.
- Franz von Kobell's well-known German drinking song 'Ein König ist der Wein', 19th century and long public domain, so not covered by the batch rule on modern commercial songs. Confirmed word-for-word against volksliederarchiv.de and musicanet.org, which both give the same text and credit the music to Adolf Eduard Marschner's setting (a separate, better-known setting by Friedrich Silcher also exists for the same words, but this score is paired in the same PDF with another Marschner song, 'Warum bist du so ferne' / 'Gute Nacht', crediting 'A. E. Marschner' directly, so Marschner is used here). 'Warum bist du so ferne' is not included as an extra song since it already exists in the catalogue as id 265.
