# Nú yfir heiði háa

Nú yfir heiði háa, um hraun og móa gráa,  
við látum skella á skeið,  
og kærum okkur eigi, þótt einhver karlinn segi:  
„Og það er þrælareið.“  

(Halli, halló, halli, halló! Já, látum skella á skeið.)  

Það batnar, batnar leiðin, og bráðum þrýtur heiðin,  
þá hvíla verðum vér.  
Sjá, skjól og hestahagi er hér í þessu dragi,  
af baki hlaupum hér.  

(Halli, halló, halli, halló! Hér hvíla verðum vér.)  

## Notes

- **Stanzas:** 2 set in the score, 2 written here.
- **Form:** No. 1 of 'Fimm þjóðlög fyrir karlakór' (arr. Páll Pampichler Pálsson, © 1974), a riding/travel song: 2 verses, each followed by a short 'Halli, halló!' riding-call refrain whose tag line changes to match the verse ('Já, látum skella á skeið' / 'Hér hvílum verðum vér'), so both are written out per the formatting rule. Both refrains are marked here with '(...)' since they function as a recurring call rather than a sung poetic line, matching the score's own bracketed/echoed presentation. Within each verse and refrain the score repeats short phrases immediately for musical effect ('við látum skella á skeið' x2, 'og það er þrælareið' x2, 'af baki hlaupum hér' x2, 'halli, halló' multiple times) — written once each here per the no-duplication rule. Voices enter canonically (1./2. Tenór and Bassi staggered by a beat) but sing the same words, so only one text line is kept per phrase.
- Confirmed via Firecrawl search: the full text is published as poem 220 ('Ferðavísur', lyricist 'Páll Jónsson') in the 1915 songbook 'Íslensk Söngbók: 300 söngtextar með lagboðum' (archive.org), matching this transcription's wording exactly for both verses, and independently corroborated by a shorter excerpt quoted on skagfirdingur.is (a horse-riding club page using the same verse 1 as a slogan for a 'skeið' gait course). The lyricist credit is simply 'Páll Jónsson' as printed in both the score and the songbook — no evidence found that 'Árdal' belongs here, so the earlier guess is dropped. One real difference from the score: the published poem's refrain is 'Halló, halló, halló, halló!' (four times 'halló'), while this score's engraving clearly alternates 'Hall-í, hall-ó, hall-í, hall-ó!' (verified directly on the page image) — kept as engraved, since it reads as the choral arranger's (Páll Pampichler Pálsson, 1974) own echo-effect embellishment for the men's-choir setting rather than a transcription error.
