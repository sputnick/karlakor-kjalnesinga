# Móts við sólglit sólarfalls

Móts við sólglit sólarfalls  
svífur ljóð af munni.  
Syngur milli fjöru' og fjalls  
fugl í hverjum runni.  

Þegar fannir skóf í skor  
og skefldi' að kofa mínum,  
hugalöngum valdi' ég, vor!  
vist í faðmi þínum.  

Víst er fagurt vor í skóg,  
veglega júní málar.  
Fegurst alls hins fagra þó  
er fegurð stórrar sálar.  

Þeim, sem lengi veitull var  
vaxtargengi þjóða,  
skært frá engi eilífðar,  
óma strengir ljóða.  

## Notes

- **Stanzas:** 4 set in the score, 4 written here.
- **Form:** 3-part male-choir (TTB) setting by Birgir Helgason ('Radds. fyrir 3ja radda KK / Af Birgi Helgasyni'); the melody carries all 4 stanzas via a verse repeat marked '1.2.3.' (a short 1-2 word close: 'runni.'/'þínum.'/'sálar.' for verses 1-3, then loop back) and a separate, longer '4.' ending for the last verse, which repeats its own closing line ('Óma strengir ljóða.') as a coda; that repeat is not written out again in the text since it adds no new words.
- check_song.py flags 'svífur ljóð af munni' (line 2) as a possible credit marking because it contains the word 'ljóð' - this is a genuine lyric word here (a noun in the poem meaning 'a song/poem', as in '[a] song floats from [my] mouth'), not a 'Ljóð:' credit label, so it is kept. Sigurjón Friðjónsson (1867-1950) wrote a longer multi-stanza poem beginning 'Móts við sólglit sólarfalls', first published in the magazine Óðinn (5. tbl., 1918). Birgir Helgason's choral setting (score marked 'Copyright © Birgir Helgason' for the arrangement/music; the underlying 1918 poem text is public domain) excerpts 4 non-consecutive stanzas from that longer poem - confirmed via web search snippets of the 1918 original (timarit.is) which show other, unused stanzas (e.g. 'Synir röðuls fell og fjöll...') between the ones selected here; those unused stanzas are correctly omitted. One line has two attested published readings: the 1918 Óðinn printing has 'Fegurst af öllu fögru þó', while a 1970 Morgunblaðið quotation of the poem has 'Fegurst alls hins fagra þó' - the score itself clearly has the latter wording, so that reading (also independently attested in print) is used.
