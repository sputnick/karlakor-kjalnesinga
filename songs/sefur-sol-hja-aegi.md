# Sefur sól hjá Ægi

Sefur sól hjá Ægi,  
sígur höfgi yfir brá.  
Einu ljúflings lagi  
ljóðar fugl og aldan blá.  
Þögla nótt, í þínum örmum,  
þar er rótt og hvíld í hörmum,  
hvíldir öllum oss.  

## Notes

- **Stanzas:** 1 set in the score, 1 written here.
- **Form:** Single short stanza. The score (which has a clean embedded PDF text layer, so very reliable) sets the fifth and sixth lines as a written-out echo/variation - first 'Þar er nótt og hvíld í hörmum', then repeated as 'Þar er rótt og hvíld í hörmum' (nótt->rótt word-painting) - before resolving to 'hvílir öllum oss'; both lines were kept since they differ. A soft closing echo of 'Þögla, öllum, öllum oss' (bass voice, fading out) was treated as a musical repeat/echo and omitted from the lyric text.
- Published text (glatkistan.com, genius.com) matches the score almost verbatim ('Sefur sól hjá Ægi, sígur höfgi yfir brá, Einu ljúflings lagi, ljóðar fugl og aldan blá...'); the only difference is the score's deliberate 'nótt'/'rótt' echo pair discussed above, which the short online lyric sheets condense to a single 'rótt' line - kept the score's fuller version since it reflects what is actually sung, per the task rule for score/online differences. PROOFREAD: the handwritten score ("Sefur sól hjá Ægi.pdf") and the published text (glatkistan) both have "þar er rótt og hvíld í hörmum" only; the typeset scores' first "nótt" is an engraving slip copied from "Þögla nótt", and the line is otherwise a musical repeat, so it is now written once. All three scores and the published text read "hvíldir öllum oss" (score: "hvíld-ir"), not "hvílir"; corrected. The form_notes about a nótt/rótt echo pair are superseded by this.
- **Proofread:** "Þögla nótt í" → "Þögla nótt, í" (comma); removed the line "þar er nótt og hvíld í hörmum" (line 6); "hvílir" → "hvíldir" (last line)
