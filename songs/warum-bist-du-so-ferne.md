# Warum bist du so ferne

Warum bist du so ferne, o mein Lieb!  
Es leuchten mild die Sterne, o mein Lieb!  
Der Mond will schon sich neigen,  
in seinem stillen Reigen.  
Gute Nacht, mein süsses Lieb, gute Nacht,  
gute Nacht, mein süsses Lieb, gute Nacht,  
gute Nacht, mein Lieb!  

## Notes

- **Stanzas:** 1 set in the score, 1 written here.
- **Form:** No. 26 'Warum bist du so ferne', subtitled 'Gute Nacht', by A. E. Marschner, from the same old choral collection as 'Das Königslied' (No. 25, which precedes it in the same PDF and is already a separate catalogued entry, id 69). Single short stanza; the closing 'Gute Nacht' is echoed between voice parts as an imitative farewell refrain that is part of the written text itself, not voice-part duplication, so it is kept as printed.
- Clearly printed, legible 19th-century engraving (plate 'N.M.S. 4911', piece dated 1796 collection). Transcribed directly from the score; no web lookup was needed given the clarity of the print.
